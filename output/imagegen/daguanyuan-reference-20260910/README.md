## 原著依据与艺术设定

核对了第17、18、38、40、41、49、50回的本地原文缓存。`literary-sources.json`保存段落、出处、版本、获取日期和哈希；文本源为[维基文库《紅樓夢》](https://zh.wikisource.org/wiki/紅樓夢)，原著为公版古籍，数字整理按来源页面的CC BY-SA 4.0 / GFDL声明署名。

原著明确提及的开间、景物和陈设关系作为生成约束。各图的实际尺寸、方位、部分构件形制、装饰纹样、书画图像、镜头和光照属于美术设定。日景总览是空间设计提案；近景是各处建筑的发展参考，最终统一总图、尺寸和隐蔽连接应在后续建模阶段完成。

这套图可用于拆解屋面、梁柱、墙体、廊道、铺地、植被、水体、家具与灯光。建议先按01建立体量和道路水系，再以近景确定可见构件；以04/05和01/15对照研究同一空间的日夜表现。单幅透视图未显露的背面和内部连接仍需后续设计。

## 文件

- `01-...png`至`15-...png`：选定的独立场景PNG，原生尺寸与SHA256见`manifest.json`。
- `index.html`：本地可浏览的图册，可点图放大或打开原图。
- `prompts.json`：初始整套提示词；`generation-log.json`：实际调用的完整提示词、参考图与修订记录。
- `literary-sources.json`：原著核查记录。
- `00-user-style-reference.png`及`user-brief.txt`：用户提供的风格图与清单，保留在本地目录，未收入下载压缩包。
- `drafts/`：未选用的修订前版本，保留在本地目录，未收入下载压缩包。

生成方式：内置`image_gen`，每幅独立生成或定向编辑。图片没有经过程序绘制、替代渲染或上采样。
