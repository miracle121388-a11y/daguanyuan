# 剧情新绘与我的梦藏

这次扩展保留三维游园与三版本剧情体系，增加“实际剧情快照 → Qwen 新绘 → 动态分镜 → 私有收藏”。预设漫画继续作为参考画卷，不能计入玩家生成画作的数量。

## 玩家体验

- 在“剧情画卷”选择文学版本与一幕，再点“为此幕作画”；可以选择意境、人物或园景取景，并补充想画出的细节。
- 在推演中点“此刻作画”，或交谈后点“将这句心声入画”。当前快照包含真实版本、主世界／IF线、在场人物、地点与已完成的行动。
- 填入已有访问口令后，可以开启“后续关键剧情自动作画并收藏”。入局、临场抉择、小聚完成触发作画；普通每一步和每次交谈不会连续自动提交。
- 等待时可继续游园；完成提示可展开全彩动态画卷。镜头推近、环境粒子与逐镜旁白支持暂停、手动切镜、减少动态和手机布局。
- “我的梦藏”按版本筛选、珍藏，下载原图或完整剧情记录；防剧透设置覆盖画册与到达提示。没有生成过图片的访客看到空画册。

## 接口与存储

用户指定 Qwen 最新生图模型并提供密钥。2026-09-17 查阅[阿里云官方 Qwen 3.0 API 文档](https://help.aliyun.com/zh/model-studio/qwen-image-generation-and-editing-api-reference)，并实际验证账户模型列表包含 `qwen-image-3.0-pro`。当前配置使用该模型及北京兼容旧域名，接口为 DashScope 异步协议。

API 密钥仅在 `.env`／服务端环境变量 `IMAGE_API_KEY`，不在浏览器、公开包或画作元数据中。作画访问口令沿用 `LLM_ACCESS_TOKEN`，可单独设置 `IMAGE_ACCESS_TOKEN`；口令在页面内存保存，刷新后需重新填写。客户端另以随机画册凭证隔离画作，不能通过猜测图片 ID 读取另一画册。

`POST /api/dreams/jobs` 先保存任务并立即返回；服务端提交模型任务、保存服务商任务编号、轮询、下载原图。已受理任务重启后继续查询；手动“继续查询原画”不重复提交生图。没有取得服务商任务编号的超时属于结果不确定，提示用户先核对服务商记录。

同一画册中，相同剧情快照与画意复用任务。修改画意会产生新图；真正重新请求失败的生图可能再次计费。默认全站每日最多 20 次提交（UTC 日界），1 个并行任务、最多 5 个待处理任务，单图上限 18 MiB，服务端画册上限 512 MiB。次数是本站限制，不是服务商余额或价格。

图片取回限制为可信服务商域名，校验公网地址并固定 TLS 连接的目标地址，拒绝重定向与超大数据；本站再以私有接口交付图片，不依赖服务商的临时外链。客户端验证 SHA-256 与解码后，将原图、剧情、珍藏标记存入 IndexedDB。服务端使用该服务专用 `/data/dreams` 持久卷；本地开发默认 `.local/dream-art`。

本机画册属于当前浏览器配置；清理浏览器数据会移除本机图片和凭证。已打开的页面断网仍可查看已保存图片，完整网页离线启动未实现。重要画作可下载原图和 JSON 记录留存。服务器为单实例文件队列，不应多个进程同时写同一目录。

## 文学与美术边界

原著资料仍来自经过审阅的 `data/canon`。八十回、程高一百二十回与癸酉一百零八回的剧情语境隔离；癸酉后续节点仅基于已经审阅的公开回目，不宣称收录全部续文或验证了作者真伪。详见 [STORY_VERSIONS.md](STORY_VERSIONS.md)。

提示词固定人物造型与工笔重彩的国风漫画方向，选用本站审阅过的漫画作造型参考，同时要求重新构图。剧情指令与已执行动作区分；托付、愿望和计划不应被当成已经发生。模型输出仍是艺术演绎，不是原著证据，细节一致性不能保证。

每幅图记录版本、分支、快照、触发原因、文字、画意、模型、提示词版本、准确提示词、提示词哈希、参考图哈希与原图哈希。生成内容不写入公共 canon。真实验收图及对应来源记录在 `output/imagegen/dream-live/`，不作为每位玩家默认已获得的画作。

## 当代游戏参照

2026-09-17 查阅任天堂的 [Pokémon Pokopia 官方页面](https://www.nintendo.com/en-ca/store/products/pokemon-pokopia-switch-2/) 与 PlayStation 的 [Share of the Week: Sun](https://blog.playstation.com/2026/07/17/share-of-the-week-sun/)（含《无限暖暖》玩家照片）。这里借鉴的是玩家经历、场景创作与拍照留念的关系。

本产品据此作出的设计选择：收藏来自自己经历的剧情，保留每幅图的故事缘由；相同书中起点可因玩家选择长出不同画面；生成等待不打断游园。没有加入抽卡、虚构稀有度或消费排行榜，也不声称这些参考游戏采用本项目的 AI 生图机制。

## 验证证据

`dream-live.json` 记录真实 Qwen 出图和相同请求复用；最初同步等待超时与异步下载被本机代理 DNS 拒绝的记录分别保留，修复后继续取回同一个异步任务。浏览器脚本读取真实图片验证画册与动态播放；随后明确拦截新建请求测试排队、失败与自动触发，不将测试状态冒充新的真实生图。

`npm test` 包含画册隔离、并发去重、持久化额度、异步恢复、图像格式、文学边界、实际选择、人物对话与退场人物约束。`scripts/dream_smoke.mjs` 与 `scripts/dream_edges_smoke.mjs` 覆盖桌面、390／320 像素、下载、IndexedDB 恢复、静态分镜、防剧透与重新填写口令后的原任务恢复。具体运行结果以各报告为准，部署结果另见 [DEPLOYMENT.md](DEPLOYMENT.md)。

2026-09-17已在原California服务部署v5，线上一次真实Qwen任务生成1536×1024原图（2,211,741字节）；从提交到保存约7分35秒，是单次观察而非延迟保证。相同请求复用、重启后原图与一次提交记录保留均已验证。线上23+7项新功能、24项三版本回归及原游园检查通过，全部23张线上截图已打开核对。报告分别为 `dream-live-online.json`、`dream-persistence-online.json`、`dream-online/` 与 `dream-release.json`。本机默认网络连接仍关闭；成功公网检查使用只对测试请求生效的公共DNS解析，TLS校验开启，未修改系统网络。
