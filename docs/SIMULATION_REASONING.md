# 人物推理

DeepSeek 的人物行动和连续对话使用 `thinking: enabled`、`reasoning_effort: high`，每次最多 8192 输出 token。条件解析和已发生事件摘要维持快速模式。按官方思考模式接口实现：https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/ 。其他兼容服务仍使用原有协议，不擅自传入 DeepSeek 专用参数。

每次决策只能读取此人感知、自己的六条相关记忆、目标、关系、身体状态和计划。记忆检索保留最近两条实际经历，再补充重要消息、在场人物关联和持续计划依据；自省作为个人解释，不能升级为新事实。模型比较可行行动，最终只返回一个行动、简短理由和本人记忆编号，不把内部思考过程送给浏览器或写入存档。

服务器和浏览器均校验行动依据。模型不能引用未知记忆、凭空访问未知人物位置或违反当前身体需要／玩家托付；台词与传递的消息仍必须来自可知选项。运动路线、相遇、状态变化由既有规则执行，不能因模型声称成功便算作发生。动作日志保存这次选择实际引用的证据，不一律套用计划的证据。

思考类请求服务器限时 65 秒，浏览器限时 75 秒，保留撤销；条件／摘要分别为 25／30 秒。输出截断、格式无效或网络失败时不保存半步行动。原有原子快照、文学版本边界、私密知情隔离和旧存档兼容保持。

`npm test` 覆盖记忆检索、证据校验、计划约束和截断响应；`npm run test:simulation` 检查实际页面；`npm run test:simulation:model` 为显式付费模型验收，进行一次条件解析、八次独立人物决策和两次摘要。验收时会明确选择托付对象，避免跟拍切换人物造成错误断言。真实模型输出仍有变化，不将有限样本当作所有剧情质量的保证。
