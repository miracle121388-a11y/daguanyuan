## 单一几何来源

`config/garden.layout.json` 的 `terrain.lake.outline` / `holes` 是唯一水陆边界。Blender 使用带孔轮廓建立地面；WebGL 水面与园图使用同样的顶点。路径图直接用于造路和导览，不再根据“中点在水中”自动把错误道路变成桥。

运行 `npm run spatial:check` 检查水陆多边形、普通路穿水、桥头落地、主要建筑落地、各入口坐标和原文明示的关键邻接关系。检查报告仅证明本方案的几何一致性，不证明唯一原著平面。尺寸单位米均为建模设定。

保留 15 个可选择地点、图录、人物回目和屋内/剖视交互。远景树使用 CC0 Island Tree 01 的实际 Blender 渲染轮廓作为 LOD，近处使用三维树冠；所有建筑、地形、山石、桥廊均为可编辑三维网格。图片不是建筑的替代物。树木源图、叶片遮罩、烘焙参数与 SHA-256 一并保存。
