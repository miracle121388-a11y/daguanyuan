# 第80回之后的故事

三个版本的新世界统一从第80回结束开始，各自独立保存。

|版本|主世界行为|结束范围|
|---|---|---|
|前八十回|真实模型根据前情创作新剧情，不预设续本结局|开放续演|
|程高本|取当前回完整正文，由模型精简演绎并独立校对|依序81—120回，之后停止|
|癸酉本|取用户提供PDF转换后的当前回正文，由模型精简演绎并独立校对|依序81—108回，之后停止|

主按钮直接可达，续本显示下一回数；自由推演显示发展方向。起点不再可改为74、91或105回。IF世界由模型按改变后的条件创作，不继续强制沿续本原文推进。旧存档保留原键值，不将旧起点强行解释为80回；高级设置可导出旧存档。

一次推进包括模型生成、独立模型复核、结构及地点校验、可执行的三维节选、原子保存。取消、超时、无效结果或来源不一致都不会推进回目。程高和癸酉每次只给模型当前回正文、80回终点参考及已演绎的历史，不提供未来回目。来源回数、标题、底本和SHA-256由服务器填写，随正文及快照保存；客户端不能伪造来源。续本保留最多64份快照，自由推演保留30份。

## 原文与私人来源

前八十回和程高正文来自已核验的维基文库数字汇校本；后40回以程甲本为底本，不是独立程甲刻本逐字校勘。服务器为新故事提供80回末尾6000字符及此前相关片段，这不等于模型已经通读80回。

癸酉采用用户提供621页PDF转换所得108份分回文件。公开原文库仍不发布这份私人正文；经 `data/canon/playbackSources.json` 审核来源及哈希后，部署工具仅将它打包到服务器 `server/private-corpus/guiyou108/`，不放入静态目录或Git。转换和复现见 `TEXT_CORPUS.md`。批语、按语从叙事投影中排除，不能把预言或编者猜测演成当回事实，也不认证作者及版本真伪。正文缺失或损坏时直接报错，禁止跨版本补造。

自由推演或IF可另行导入仅截至80回的TXT/Markdown（UTF-8或GB18030，最多5MB/150万字）；检测到后续回标题时拒绝。正文按不超过16000字符分片，由模型逐块合并累积档案，并保留末尾6000字符。只有全部读取成功才保存摘要、哈希及尾段，全文不在浏览器持久化。导入会发送至配置的模型服务，多次调用产生时间和费用，摘要压缩可能丢失细节。续本主世界不需要用户重新上传整本，也不进行全书逐块模型阅读。

## 文学叙事与三维表现

续本是有原文依据的改编演绎，目标900—1500字，禁止整回照抄；自由推演是独立新创作，不声称推得作者唯一原意。人物仅获得本段亲历或明确获悉的新事实，已死人物不能复活，幻境显现不算肉身复活。

正文可以包含配角及园外事件；三维只展示现有四个人物、园内现有地点中确实发生的行动。没有合适镜头时允许空镜头列表，不为动画伪造情节。结构校验和独立模型复核不能保证文学细节完全正确，应逐回阅读判断。

`npm test` 覆盖统一80回起点、续本所有回号推进及终点停止、保存读回、IF转换、伪造来源、缺失正文、取消与复核回滚。`npm run test:continuation:model` 在配置LLM_*后真实调用模型，默认三版本各两段；实际报告明确区分模型验收与模拟场景执行器，不宣称验收全部续本回目的文学质量。模型上游诊断仅在设置 `GARDEN_MODEL_TRACE=1` 时存入 `.local/`，不能提交私人正文和请求信息。
