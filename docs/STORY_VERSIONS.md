# 三版本与动态漫画

从顶栏 **剧情画卷** 或 **世界推演 → 选择一幕，走进书中** 进入。选择文学版本、剧情节点，再点“展开动态漫画”或“从此幕入局”。支持暂停、前后分镜、重播、Esc 返回、系统减少动态和手动关闭关键节点自动展开。

三版本分别保存在本机浏览器。切换版本恢复各自进度；进入剧情会新建 IF 线并保留主世界，已有 IF 按原机制进入历史线。新的剧情起点使用新的个人记忆，不继承另一个回目的未来消息。此后对话、抉择与行动仍为虚构推演，不自动强制走到书中的结局。

| 版本 | 已接入起点 | 内容边界 |
|---|---|---|
| 前八十回 | 27 葬花、37 诗社、74 抄检 | 沿用本项目已审核数字文本，未宣称为单一脂本的校勘；第80回以后不预设结局 |
| 程高120回 | 共同节点，加97焚稿、105查抄 | 对应片段已核对，晚期起点据第98回限制黛玉出场；不是全120回逐回剧情库 |
| 癸酉108回 | 共同节点，加82独吟、90待好姻、91戒严 | 后续据2014九州版公开目录设定改编起点，未核对或分发全文；前80回借用共同资料，未校勘其异文 |

“癸酉本／吴氏石头记”的来源与真伪有争议，不作为曹雪芹原稿的定论。其具体版次固定为[ISBN 9787510827310 的2014年版公开书目](https://www.sanmin.com.tw/product/index/004615400)，不把其他网络修订本的回目混入。程高后四十回与前八十回分开标注，不把作者归属讨论写为定论。来源讨论参考[吴氏石头记版本记录](https://zh.wikipedia.org/wiki/吴氏石头记增删试评本)。

## 文学、舞台与美术

`data/canon/editionCatalog.json` 是新增的审核数据，保留来源定位、短引文、获取时间、原始与规范化文本 SHA-256。原始研究档案在 `data/raw/editions/`，不进入网站。构建仅从已审核 canon 发布资料。

三维院落、人物摆位、天气、开场数值和旁白是改编。园门可借景承载府外事件；不能从图中有人便推断原文同场。癸酉第91回的凤姐尤其明确为舞台人物。原有22个文献事件、地点模型、Blender母文件与手工调整不改。

五幅图由内置 image_gen 制作：葬花、诗社、焚稿、风雨园门、竹窗。原图和完整提示词在 `output/imagegen/story-comics/`；来源与衍生图哈希在 `data/canon/comicArt.json`。运行时使用本站 `public/comics/` 的 WebP，不调用外部生图服务。手机预览使用小图，全屏漫画使用完整分辨率。

每个节点有三镜，叠加运镜和花瓣、微光、火星或雨。既有诗社／抄检文献事件可触发对应漫画；从剧情起点入局、该起点的临场抉择，以及第37回以后的已完成小聚也可触发画境。IF画境借用插画表达情绪，实际选择结果以日志显示，图中动作不冒充已执行动作。单幅底图多镜运镜不是逐帧角色动画。

## 构建与验证入口

- `npm run content:editions`：从已归档证据重建人工编写的关键节点；不会自动抓取并发布未经审核剧情。
- `npm run content:comic-art`：从项目原图重建两档 WebP 和来源清单。
- `npm run build`：资料校验、发布、类型检查、正式打包。
- `npm test`：版本隔离、旧档兼容、未来记忆边界、剧情起点、服务端请求边界等。
- `npm run test:story`：桌面／390／320浏览器流程；`STORY_REPORT_DIR` 指定结果目录，`APP_URL` 指定待测站点。
- `node scripts/story_model_smoke.mjs`：明确发起三次真实模型交谈，从本机环境读取访问口令，不将凭据写入报告。

旧无版本存档归入八十回工作区，原 IF 条件仍作为用户假设保留。无法读取的旧存档会先备份再保存新世界；存储受限时保留内存状态并提示导出。版本信息同时进入导出存档与推演纪要。人物只接收本人记忆和当前版本边界，后续模型文案仍需按具体使用情境判断，三次接口验证不证明长期文学一致性。
