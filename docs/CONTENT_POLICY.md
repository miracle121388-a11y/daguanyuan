# 内容规则

维基文库分回页面是数字文本来源，不冒称已经辨明单一权威校勘本。原始HTML、规范化正文和段落JSON保存在 data/raw；正文用UTF-8、LF固定换行，原始与规范化哈希分别保留。

`scripts/prepare_content.py`中的人工撰写记录由执行代理对照缓存原文审阅。自动程序只负责定位、模式与外键检查，不能自动保证文学解释准确。语义理由逐条记录在 reports/acceptance/content-review.json，审核状态始终是 source_checked，而非 editor_reviewed。

居住关系、事件参与者、实时位置相互独立。仅第23回明示的五人入园居所写入residencies，结束回目未知则保留null。没有依据的外部人物不写成园中常住。

第23回共读西厢的地点是沁芳闸桥边，canonicalPlaceId为空，displayPlaceId为潇湘馆。分居事件涉及全园，借入口展示。第74回探春院落依据第23回居所关联定位，明确标为推定。芦雪庵名称与形制补核第49回，第50回联诗通过连续场景交叉核对。

仅核实的字形进入aliases；其他版本说法保留待核，不做自动同义替换。小说未给出的尺寸、绝对方位与建筑细节标为interpretive。三条路线全部是策划路径。未加入人物移动情节演示或AI新编数据。

发布白名单只含规范化结构数据，不拷贝原始、待审资料或本机文件。防剧透同时控制事件、人物文案、回目、关联来源与地点描述；点击未来事件会被状态动作拒绝。
