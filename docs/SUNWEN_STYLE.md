# 孙温绘本：本轮三维美术依据

本轮以用户指定的 [changren-wcr/sunwen](https://github.com/changren-wcr/sunwen) 为唯一建筑配色与园林画意标准。固定提交 `9e9352d51a5f4a7006f77946ee8ace29d427a937`，目录共 203 图，下载并核验其中 42 幅原图。原来的 AI 园景图已退出网页图录及建模依据；原始生成档案仅作历史留存。团队的剧情画卷、梦藏和世界推演不属于这次美术资料替换范围。

原图在 `references/sunwen/originals/`；`provenance.json` 记录上游路径、Git blob SHA-1、文件 SHA-256、尺寸、回目和下载地址。原作与数字扫描的权利说明分别记录，不把 GitHub 上公开可见误写为扫描文件具有明确的开放许可。网页只读取本地 WebP。

画作提供色彩、形态和疏密关系；RGB 色值、三维树形、种植位置、同景花期与对应院落均含设计转译，不宣称为颜料测量、实测复原或原著植物学证据。文学出处与空间解释继续沿用已审核的 canon。

`config/garden.sunwen.json` 定义色彩和树种形态，`config/sunwen.planting.json` 保存最终种植坐标。原种植坐标存于 `assets/processed/planting-r17/source.json`，用于重做疏密选择并保留地面高度。没有迁移地点、道路、水陆边界或剧情角色使用的坐标；原建筑拓扑与 `Manual_Adjustments` 保留，新增彩绘位于独立生成集合。

在 Conda 环境内运行：

```sh
conda activate daguanyuan
npm run references:sunwen
npm run models:sunwen
npm run sunwen:check
npm run build
npm run dev
```

`models:sunwen` 会更新可编辑母场景、八类树冠、庭院花卉、彩绘构件、移动端模型、光影图与压缩 GLB。`models:build` 的完整重建也在原有结构生成之后应用这套美术方案。所有运行资源来自本地，不依赖 GitHub 或生图服务。

## 经营式园林的地面与植物规则

用户在本地预览后进一步明确：整体为工笔重彩的清代贵族私家园林，青绿为底、花木繁盛，禁止黄土荒地、自然野林、单一深绿、现代大草坪和欧美自然花园。浅色画纸或画中留白不再转译成大片裸土。地面以青石、卵石、院坪、低矮地被、局部苔痕与湿润岸线组成；种植围绕建筑、廊桥、院墙和水体成组，保留入口和轴线视线。

- 怡红院：海棠粉红、芍药、芭蕉；侧庭繁盛，正面院坪清楚。
- 潇湘馆：修竹、芭蕉、灰绿与竹青地被、白花和苔痕；泉渠与竹径留通。
- 蘅芜苑：灰绿芳草、山石藤蔓、少量素白花；通道整洁，克制素雅。
- 稻香村：果木、低矮花篱、整齐小田畦，嫩绿与菊黄相间。
- 藕香榭与水岸：柳、粉荷、鸢尾分湾聚植，大片水面继续用于倒影与借景。

本轮结果：88 处种植分区，238 株乔木、123 组低灌木，918 组多年生花木（含 240 组荷花），另保留 360 组低草与 240 组蕨类。几何花瓣、叶裙与石边组成连续花坛；近景使用完整花茎，远景保留低矮花色。花期组合表达画意，不作写实物候或原著种属断言。

`config/sunwen.landscape.json` 是地表、花坛与矮植被的共同配置。`scripts/prepare_sunwen_ground.py` 从配置生成世界坐标材质图；`blender/install_sunwen_landscape.py` 将地被、花坛石边和花卉放入可编辑母场景，并沿真实地形射线落地。新增集合为 `Sunwen_Garden_Details` 与 `Reference_Sunwen_Planting`；原建筑、道路、水陆边界与手工集合保留。网页与 Blender 共用材质图和种植坐标，资源全部本地化。

仅调整景观时可在 Conda 环境运行 `npm run models:sunwen-landscape`，复用已有建筑结构导出。轻量版单独精简远景山石、细枝和低叶裙，保留庭院结构、详细模型和原始可编辑母场景。`npm run models:sunwen` 仍可完整重建全部导出。

## 府邸腹地与京城屋顶 r19

大观园外围采用高密度低层宅院，分为贴墙夹道与后罩房、宁荣府邸式多进院落、远处京城屋顶三个层次。264 组院落以青灰瓦、浅灰墙、素木构和少量院树组成连续背景。6.2 米实体园墙、入口照壁和墙边树冠遮挡平视视线；楼阁与俯瞰镜头可越墙看到连续屋面。园内假山与凸碧地形保留，环园远山退出展示。街坊地面使用独立灰石材质，不延续草地或黄土。

`config/garden.urban.json` 定义园界、地坪、墙高、街坊密度与色板。`Urban_Context` 保留每个建筑和院墙的可编辑实例，`Urban_Prototypes` 存储共享原型；`Urban_Garden_Ground` 是按园界与入口地坪裁切的地形。旧外围地形和 19 株外围树以 `urbanRetired` 标记隐藏留档。运行时使用同一批原型和变换，实例化绘制，所有资源在本站。

在 Conda 环境内执行 `npm run models:urban`，依次生成母场景、替换两档全景地形、烘焙真实阴影并压缩导出。`npm run models:urban:check` 校验园内原网格保留、地形范围、外城楼高、原生与网页变换对应，以及四向低视角遮挡和高视角开敞。入口地坪延伸到原有到达点之外，不改动导航锚点。

外围院落的坐标、数量与体量是依据用户空间要求的营造解释，不是宁荣二府实测复原，不新增 canon 地点或文学路线。

## 京城街坊差异与城市设施 r20

取消 r19 的等距方格和统一四合院模板。街坊保留京城街道总体方整的关系，使用大小不同的地块、不同进深的府邸院落、错开的次巷和局部门前空间。靠园一侧是宁荣府邸式深院及办事院；外侧穿插普通宅院、偏门小院、仓房、客栈、沿街商铺和小庙院。深院分成连续的两进或三进院落，正房两侧配低耳房，较长厢房分栋，避免把同一座房子拉伸成长条。

住宅以硬山青灰瓦为主；府厅、门楼和庙殿用舒展的四坡屋面，少量两层铺面和钟亭形成高低变化。屋顶采用青灰、蓝灰和旧暖灰，街面点缀栗木、赭红、灰绿和米赭布棚。具体设施包括三间牌坊、胡同栅门、覆顶井台、钟亭、店棚、货车、拴马栏及石砌排水沟和过沟石板。设施集中在庙前、府前街、市集和巷口；街道仍以步行尺度的灰石地面和低层建筑为主。

街坊形态学习参考 [故宫博物院《〈乾隆京城全图〉考略》](https://www.dpm.org.cn/paints/talk/203896.html) 与 [东洋文库／日本国立情报学研究所《乾隆京城全图》](https://dsr.nii.ac.jp/toyobunko/II-11-D-802/index.html.en)。参考的内容是宅院、庙宇、街道等不同城市空间共同组成京城的关系；本项目没有照搬地图中的地点、坐标或招牌，也没有把这些外围设施加入原著地点和导览路线。美术设色继续服从孙温绘本的园林世界。没有新增外部图片或网络运行依赖。

`blender/urban_layout.py` 生成可重复的街巷地块和建筑布置，并在导出前检查含出檐范围的碰撞；`blender/urban_architecture.py` 生成 24 类共享构件。`urban_context.py` 将同一布置保存到可编辑母场景和网页实例表。配置、生成器与衍生模型的 SHA-256 记录在资源清单中。外围核验还从母场景实际网格重新计算屋檐包围范围，并比对 r20 开始前的园内建筑、花木、铺地细节与手工修改。

复现仍使用 Conda 环境内的 `npm run models:urban`、`npm run models:urban:check`。浏览器回归使用 Playwright 配套 Chromium；可通过 `GARDEN_BROWSER_CHANNEL` 选择已经安装的其他浏览器，不依赖系统预装 Edge。

## 地表与树下种植的衔接 r21

取消“种植椭圆之外默认碎石灰”的园内底图。浅豆绿草本、灰绿地被、青绿苔地与少量湿润叶土交错，树丛下较深、空隙处较浅；水岸过渡加宽到 3.6 米并柔和衰减。主要通道仍用卵石和青石，院落、主轴和建筑入口保留硬质铺地。扣除水面后的材质分区中，柔性地表约 70.52%；这是地表底图面积统计，包含建筑覆盖处，不是屏幕像素占比。

依据母场景的 360 处实际乔木／灌木根点生成不等宽的树下地被，并用 491 段短连接组织邻近树丛。墙边树冠共用起伏的窄种植带；新增 2400 簇方向、尺度和数量不齐的低叶、细茎及少量花瓣，保存于 `Sunwen_Root_Gardens`。它们随景观模型显示，不依赖近景花卉实例的显示距离。北墙一株白花树由 `[38,141]` 移至 `[32,136]`，让开原路径；其余树木变换和原有建筑、花坛、城市背景、地形、手工网格均保留。

另外从院落树皮网格的实际下部树干环中识别出 22 处原有树木根点，包括怡红院花树、稻香村果树与大观楼庭树。这些树不属于独立树木实例表，现同样获得贴合实际铺地的树下种植。两处靠石径的固定树脚使用窄小苔地树池，范围不达路径中线；其树干和建筑网格保持原样。360 处独立根点与这 22 处院内树脚均通过网页材质采样。

配置为 `config/garden.grounding.json`。`extract_garden_grounding.py` 读取原生根点，`garden_ground_fields.py` 计算共用地表分区，`prepare_sunwen_ground.py` 生成本站材质图；`install_garden_grounding.py` 按实际地形与铺地射线安放低层植物。地形已有相同颜色场，额外贴地面仅用于院内树脚与确有高起石面的局部，不重复覆盖全园。网页地形和这些小补面共用颜色与实际阴影，避免边界色差。叶簇的原生完整几何保留，移动端在独立临时场景中简化，导出仅包含当前场景，避免重复带入精细版。

在 Conda 环境内运行：

```sh
npm run models:grounding
npm run models:grounding:check
npm run sunwen:check
npm run build
```

只重做景观轻量版用 `npm run models:grounding:lod`。完整孙温模型流水线也已接入这一步。建筑、外围城市和地表使用各自组件版本，当前城市仍是 r20，当前整场景为 `spatial-garden-20260918-r21`。根点方案、母场景、模型和材质均有哈希记录，具体种植与地表设计仍是美术解释，不扩写 canon。


## r22 · 深宅藏园的遮挡层次

原著第十六回写到借用东府花园、审察两府地方营造省亲别院，作为府邸腹地关系的依据（[原文](https://zh.wikisource.org/wiki/紅樓夢/第016回)）。本项目京城意象、具体墙线、宅院坐标、树木与观景高度属于美术和空间解释，不作为原著实测平面，不新增 canon 地点。

在原有实体高墙内侧的窄带中补入 72 株高低交错的孙温槐树、银杏与白花树，配 25 丛竹、15 组低叠石、72 处树下花叶以及 6 段短回廊。所有新增树脚均采样确认落在 r21 软质地表，原有 360 株乔灌木、院内 22 处树脚、花坛、建筑和湖岸保留。密植局限在园墙边缘，园中主要建筑和轴线仍有留白。

墙外新增 45 段高低、长度不同的后罩房和四向府内夹道，之后才连接原有 342 组府邸与京城街坊。近府内新增 89 株庭树、扩大 52 株原有庭树，141 处树脚配种植地与低叶，形成屋脊和树冠交叠的第二层背景。原牌坊、井台、庙院、市场及胡同体系保留。新模型 222852 字节，网页和 Blender 共用原型与实例变换。默认全园镜头提高俯角，让园景占主要画幅。

四向 166 条实际屋顶抽样：2.2 米平视全部被实体墙遮挡；12 米观景高度有 60 条穿过墙和真实树冠，27 米有 128 条可见。使用真实网格射线，场景不会按相机高度突然开关城市。更高的鸟瞰仍可看清完整街坊。

复现使用 Conda 环境内的 npm run models:urban、npm run models:urban:check、npm run sunwen:check；macOS 指定本地 BLENDER_BIN。边界配置在 config/garden.urban.json，窄带植栽由 blender/urban_screening.py 生成，既有树木不再被外围生成器反复重建。当前整场景 spatial-garden-20260918-r22，建筑 r18、地表 r21 保持。完整验收见 reports/acceptance/r22-enclosure-release.json。
