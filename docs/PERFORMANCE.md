精细模式加载完成后等待 6 秒，读取最近至多 300 帧。P95 为 12.6 毫秒。该指标是无头浏览器回调间隔，不能将其倒数直接当成屏幕实际显示帧率。采样未隔离系统其他图形负载，单次总览采样不能代表所有院落和导览的最差情况。

轻量模式等待切换完成后清空帧序列，通过 150 次鼠标轨道移动采样。按需渲染的空闲间隔不能解释为渲染性能；脚本仅纳入 0—250 毫秒的有效回调间隔，最后取 300 帧，因此轻量平均值不应换算为持续显示 FPS。两个场景动作不同，不将该表当作严格同负载比较。

几何估算按场景中唯一 BufferGeometry 的顶点/索引数组求和；纹理按宽×高×4×4/3估算。它们不包括驱动、帧缓冲、缓存的隐藏资产等，不是显存实测总占用。轻量总览按地点合批并使用顶点色，保留地点粒度的剔除；静态阴影只在场景变化时更新。两模式均低于任务书的 120万 / 35万三角面与 200 / 100 绘制调用起步预算。

## 资源体积

- 精细首页 Resource Timing 实际资源传输合计：4.62 MiB（含脚本、样式、数据、总览；不含导航文档的微小开销），低于约20 MB目标。无远程字体或外部 API 依赖。
- 发布总览 GLB：4.05 MiB；轻量总览：0.59 MiB，相较上一版15.78 MiB减少约96%。模型包含 Draco 几何压缩，浏览器从本站加载解码器。
- 两种总览加12个精细分区、12个手机分区，共26个模型合计 24.58 MiB；离线 gzip 估算约 23.42 MiB。实际服务器直接传输 Draco GLB，文本与解码器支持 Brotli/gzip。发布包约35.3 MiB，低于现有套餐50 MiB上传限制。
- 正式应用 JS 两个分包合计 gzip 约360 KB，CSS约6.1 KB。分区选择后请求；精细缓存4处、轻量缓存2处，退出缓存时释放几何与纹理。
- 精细纹理为1K、DPR上限1.5；轻量DPR上限1，首页总览不加载纹理。触摸设备默认轻量，包括横屏设备。

## 复测

先运行 `npm run test:e2e` 生成独立 `.test-dist/`，在一个终端执行 `npx vite preview --outDir .test-dist --host 127.0.0.1 --port 4175`，另一个终端执行 `node scripts/performance.mjs` 与 `python scripts/write_performance_report.py`。性能调试钩子只存在于测试构建，正式构建已验证移除。

未进行真实手机GPU、热稳定性或长时间内存压力测试；模拟结果不能替代真实iOS/Android设备验证，不据此声称所有设备稳定60 FPS。线上跨地域延迟和首屏时间可能与本地限速模拟不同。
