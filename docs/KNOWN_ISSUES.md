# 已知边界

- 本园为《红楼梦》文学空间的美术解释。方位、尺寸和建筑形制没有实测考据依据；界面已标注。它是风格化园林，不是影视场景或历史建筑测绘复原。
- 外部完整古建模型未取得：两个 Sketchfab 候选页面无法取得可靠许可与下载文件，ACA 许可未核实，均未使用。建筑、植被由本项目自建模块生成；实际采用四项有来源记录的 Poly Haven CC0 资源。
- 文本取自维基文库数字整理，保留修订号、获取时间、原始及规范化哈希。已由执行代理逐条查阅所选依据，未经人类红学专家审定。人物关系仅发布有直接证据的一条亲属关系，其他关联由已核实居所与事件驱动。
- 22 项事件覆盖 13 回，属于精选阅读内容，不涵盖全书。防剧透控制内容与引用；地点名与人物姓名作为索引仍然存在。共享西厢等情节的展示位置与原著发生地明确分开。
- 最终精细总览本机采样平均回调间隔约9.3毫秒、P95约12.6毫秒；轻量拖动约8.2毫秒、P95约12.7毫秒。无头浏览器指标不能直接当作屏幕帧率，条件见 `PERFORMANCE.md`。低画质采用按需渲染，空闲 FPS 没有比较意义。
- 已完成390×844触摸、9 Mbps / 80毫秒网络与4倍CPU降速模拟，首屏约2.8秒；320×740窄屏控件通过。未运行真实手机GPU、Safari、设备发热或长时间内存压力测试。
- 低质量总览按地点合批、顶点色着色；细叶和纹理细节比精细模式少。选择地点后会请求对应手机分区，兼顾近景陈设与首页体积。
- 不提供任意自由第一人称碰撞与 WASD 行走；当前提供轨道观察及道路图导览。自动停靠约 5 秒，可暂停继续阅读。手动旋转会暂停导览。
- 环境声音未启用，未接入 OpenStory 或 AI 人物服务；没有虚构的实时人物在场状态。
- Windows 与 Edge 已实测。macOS、Linux、Safari、真实 iOS/Android 未运行。正式构建部署于用户现有 Zeabur 加利福尼亚服务器，域名与验证记录见 `DEPLOYMENT.md`。跨地域网络性能取决于用户网络。
- 本机代理对新域名DNS和HTTP/3存在连接异常。线上验收仅对测试浏览器指定真实公网解析、关闭QUIC后通过，HTTPS证书校验保持开启；未修改系统网络设置。遇到相同情况可换用正常网络，细节见DEPLOYMENT.md。
